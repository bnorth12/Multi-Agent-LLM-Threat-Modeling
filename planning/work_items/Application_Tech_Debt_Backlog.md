# Application Technical Debt Backlog

Purpose: track product/runtime technical debt independently from governance automation debt.

## Scope

- Application runtime logic and architecture
- API and integration debt
- UI/UX implementation debt
- Performance, reliability, and maintainability debt in application code

## Explicit Exclusions

- Governance policy routing and enforcement automation
- Independent review exception policy behavior
- Governance ledger and compliance reporting automation

Those items belong in: planning/Governance/Governance_Automation_Improvement_Backlog.md
