## Summary

The mitigations artifact produced by agent_08 (mitigation mapper) has no dedicated viewer
in the React HMI and is not included in the export panel. Analysts cannot review mitigation
records in isolation (distinct from the inline threat-linked view proposed in S12-021),
and there is no mechanism to download the raw mitigations artifact.

This is a requirements gap as well as an implementation gap:
- INT-008 requires visualization read access to mitigations but there is no viewer.
- GUI-006 lists canonical, STIX, Mermaid, and report for export but does not explicitly
  include a mitigations artifact export — this gap must be closed in the requirement and
  in the traceability matrix.

Note: S12-021 delivers per-threat inline mitigation population and per-item accept/reject
decisions. This issue is complementary — it delivers a standalone mitigations artifact
viewer (all mitigations as a flat list / tabular view) and a raw export of the mitigations
artifact (JSON or CSV).

## Scope

### Standalone Mitigations Viewer

- A mitigations subview within the Artifacts section (or as a named navigation item)
  renders all mitigations generated by agent_08 as a sortable/filterable table.
- Columns: Mitigation ID, Name, Threat ID(s), Control Type, Description summary,
  Status (Pending/Accepted/Rejected from S12-021 decision state).
- Clicking a row expands inline detail (full description, implementation guidance,
  affected components, linked threat IDs).
- The viewer is visible and populated after the mitigation stage completes, even if the
  per-item accept/reject decisions from S12-021 have not yet been delivered.

### Mitigations Export

- The export panel (S12-026) includes a mitigations export button.
- Mitigations export is accessed through the always-visible header Export navigation
  introduced in S12-026.
- Export formats: JSON (raw mitigation artifact as produced by agent_08) and optionally
  CSV (flat mitigation records for spreadsheet use).
- Export is enabled when the mitigation artifact exists; disabled otherwise.

### Requirements Update

- GUI-006 requirement text must be updated to add "mitigations artifact (JSON/CSV)" to
  the list of exportable outputs.
- PRJ-011 requirement text must be updated similarly.
- A new GUI-038 requirement (or equivalent next available ID) must be added to
  Requirements/10_GUI_Requirements.md specifying the standalone mitigations viewer.
- Traceability matrix must be updated to reflect the new requirement and link it to
  the mitigations viewer implementation.
