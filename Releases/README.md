# Releases Directory

This directory stores release artifacts and release evidence.

Use this folder for:

- Release notes
- Release checklist bundles
- Release decision records
- Signed approval evidence
- Deployment guides for each release candidate and GA release

Recommended naming:

- `Deployment_Guide_v<version>.md`
- `RC1_Baseline_And_Go_No_Go_<date>.md`
- `RC1_Final_Publish_Recommendation_<date>.md`

Current release-planning records:

- `RC1_Baseline_And_Go_No_Go_2026-05-26.md`
- `RC1_Final_Publish_Recommendation_2026-05-26.md`

Version-locked release snapshot containers:

- `v1.0.0/`
