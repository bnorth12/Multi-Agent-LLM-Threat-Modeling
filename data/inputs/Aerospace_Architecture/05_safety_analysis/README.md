# Safety Analysis Seed Corpus

## Scope

This section provides a baseline corpus for failure mode effects analysis (FMEA) and hazard safety analysis.

## Purpose

- Seed publicly sourced aerospace hazard and failure-mode references.
- Provide machine-readable hazard/failure entries for later mapping to functional decomposition.
- Support gate-oriented safety evidence planning before architecture gap comparison.

- `public_source_index.md`
- `fmea_and_hazard_baseline.md`
- `fmea_hazard_register.csv`

- `fmea_hsa_subsystem_decomposition_matrix.csv`
- `reference_architecture_gap_analysis_template.csv`
- `coverage_evaluation_tranche_11.md`

## Usage Rule

Use this corpus to collect and normalize hazard/failure evidence first. Functional decomposition gap analysis is a separate downstream step.
