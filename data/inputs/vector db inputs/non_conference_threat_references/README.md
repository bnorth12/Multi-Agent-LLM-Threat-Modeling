# Non-Conference Threat References

## Scope

Threat references from advisories, incident reports, standards bodies, and regulator/manufacturer publications that are not conference talks.

Primary canonical home for this material is now `../Aerospace CTI/`.

## Priority Source Classes

- CISA ICS advisories and KEV where relevant.
- FAA, EASA, and other aviation authority cybersecurity publications.
- NIST SP 800-series and NISTIR documents for industrial and cyber-physical systems.
- ENISA, MITRE ATT&CK ICS, and sector ISAC publications.
- Vendor PSIRTs and product security advisories for avionics/ground systems.
